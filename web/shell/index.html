BlueWake Web

The Legend of Zelda: The Wind Waker (GameCube, USA), statically recompiled from your own disc and run as WebAssembly in this browser. This is an early development build: it checks the browser runtime and prepares your disc; the game itself does not run here yet.

    Your disc

    Choose your own copy of The Wind Waker (USA, GZLE01, revision 0) as an ISO, GCM or CISO image. It is copied into this site's private storage in this browser only, never uploaded.

    Runtime check

    Starts the WebAssembly runtime on a worker thread: the GameCube CPU state and memory, the shared disc importer, dynamic loading of a module as the game module will be loaded, and WebGPU drawing on the canvas.
